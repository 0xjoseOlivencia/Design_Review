## Prerequisites

Before you begin, ensure you have the following installed on your system: [Node.js](https://nodejs.org/) 18+ and npm 8+

**💡 Tip:** If you don't have Node.js installed, download the LTS version from [nodejs.org](https://nodejs.org/).

---

## ⚡ One Command Setup & Run
### Step 1. Clone the Repository

```bash
Clone the Repo
git clone https://github.com/0xjoseOlivencia/Design_Review.git
```
*Alternative: If you prefer not to use Git, you can download the ZIP file directly from the repository page and extract it to your local machine.s*

### Step 2: Navigate to the Project Directory

Open your terminal and navigate to the project folder:

```bash
cd Design_Review
```

### Step 3: Run the Setup Command
Open the command prompt in the project root directory and run the following command to install all dependencies and start both applications:

```bash
npm start
```
### Access Your Applications

Once the installation and startup are complete, you can access your applications at the following URLs:

**Frontend**
- URL: http://localhost:5174
- Description: User-facing property listing and search platform

**Admin Panel**
- URL: http://localhost:5173
- Description: Administrative dashboard for property management


# Your Task
Review the real estate test platform and provide a UI/UX audit that answers:

- What works well in the current design?
- What needs improvement (usability, navigation, visual hierarchy, clarity)?
- What pain points do you notice?
- What suggestions do you have for improvement?

# Focus Areas
We encourage you to evaluate the platform through the following lenses:

- Navigation & Information Architecture – Is the structure logical and intuitive? Can users find what they need without friction?
- Visual Hierarchy & Clarity – Does the design guide attention effectively? Are the most important actions and information prominent?
- Usability & Interaction – Are key actions obvious and easy to complete? Are there any confusing or frustrating moments in the user journey?
- First-Time User Experience – What might confuse or overwhelm a new user? How could the onboarding or initial experience be improved?
- Consistency & Standards – Does the design follow established patterns? Are interactions predictable across the platform?
